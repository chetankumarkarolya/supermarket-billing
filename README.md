# 🛒 Supermarket Billing System in Python

This is a simple Python program that simulates a billing system for a supermarket. It allows a cashier to input a customer's name, add multiple items with their quantity and price, and generate the total bill. The program can handle multiple customers in a single session.

---

## 💡 Features

- Accepts customer name input
- Allows entering multiple items (quantity and amount)
- Calculates total cost per customer
- Repeats for multiple customers
- Friendly console interface
